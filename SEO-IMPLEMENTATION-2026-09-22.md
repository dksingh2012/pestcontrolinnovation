## Important SEO limitation
The report's External Factors score is 21% because it found 7 referring domains and 23 backlinks. Website code can improve technical/on-page SEO, but it cannot legitimately create authoritative backlinks. Therefore this package targets the controllable on-page/technical items; a true near-100 overall score also requires legitimate external citations/backlinks and cannot be guaranteed by code alone.
